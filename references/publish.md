# 6단계 썸네일 · 제목 · 설명란 · 챕터

## 1. 썸네일 2안 (유튜브 A/B용)

- `profile.json`의 `thumbnail_tool`로 만든다. 이미지 생성 도구가 있으면 16:9, 2K로 2~3안만.
- 참고 이미지로 실제 로고·실제 화면 캡처를 넣는다. 로고를 지어내지 않는다.
- 방향: A는 도구가 하는 일을 한 줄로(로고 강조), B는 확인한 사실 한 줄(비교·사실형). 두 안은 서로 다른 이유로 클릭하게 만든다.
- 글자는 영상에서 실제로 보여 준 것·확인한 사실만. 숫자는 근거가 있을 때만.
- 색·글꼴은 `profile.json`의 `brand`.
- 업로드용은 1920×1080 JPG, 2MB 이하: `썸네일/유튜브용_A_<이름>.jpg`, `유튜브용_B_<이름>.jpg`. 원본은 따로 남긴다.

## 2. 제목 후보 3개

도구·주제 이름을 앞에 둔다. 과장된 낚시 문구는 쓰지 않는다.
1. 해 본 일 나열형: "○○ AI, 블로그 글부터 견적 메일까지 시켜봤어요"
2. 숫자 약속형: "○○ 실전 활용 3가지 | 주제1·주제2·주제3"
3. 사실·후기형: "(확인한 사실) ○○, (누가) 써 본 후기"

A/B 테스트는 "제목 + 썸네일"을 짝으로 묶는다. 썸네일 A·B와 결이 맞는 제목이 하나씩 있어야 한다.

## 3. 설명란 (그대로 붙여 넣는 완성본)

양식: `templates/업로드_제목_설명란_양식.txt`. 파일: `<작업폴더>/업로드_제목_설명란.txt`

순서:
1. 첫 두 줄(더보기 전에 보이는 곳): 영상에서 실제로 한 일 한 줄 + 도구 공식 링크
2. 도구 소개 2~3문장 (영상에서 한 말 기준)
3. "이 영상에서 다루는 것" 번호 목록 (요약 카드 주제와 같게)
4. 챕터
5. 내 링크 (`profile.json`의 `links`만)
6. 해시태그 3~5개

본문 안에 작성 의도나 안내문을 섞지 않는다.

### 링크
- 도구 링크는 공식 사이트에서 직접 확인한다(다운로드 페이지 주소까지).
- 내 링크는 `profile.json`에 있는 것만. 없는 링크를 추측해 넣지 않는다.

### 챕터
- 00:00부터 오름차순, 간격 10초 이상(유튜브 조건), 3개 이상.
- 시각은 최종 캡컷 초안에서 계산한다: 하이라이트 끝 = 본편 시작, 각 요약 카드 끝 = 다음 주제 시작, 마지막 카드 끝 = 마무리.
- 챕터 이름은 요약 카드 주제 이름과 같게. 검수 받아쓰기로 그 시각에 실제로 그 주제가 시작되는지 확인한다.

## 4. BGM

- `profile.json`의 `bgm`. 기본은 맨 앞 하이라이트와 마지막 인사에만.
- 출처를 모르는 곡은 업로드 전에 사용자에게 출처를 묻고, 유튜브 업로드 화면의 저작권 확인 결과를 본다.

# 설정 인터뷰 (처음 한 번)

결과는 `~/.content-system/profile.json` 하나다(`templates/profile.example.json` 형식). 스킬을 새 버전으로 바꿔도 이 파일은 남는다.
한 번에 다 묻지 말고 아래 순서로 두세 개씩 묻는다. 모르는 칸은 비워 두고 나중에 채운다.

## 1. 채널과 링크

1. 유튜브 채널 이름 (숏폼 끝 안내 "풀영상은 유튜브 '○○'에서"에 들어간다)
2. 설명란에 넣을 링크: 링크 모음, 블로그, 인스타그램, 문의 메일 등. 사용자가 준 것만 넣는다. 열려 있지 않은 홈페이지는 넣지 않는다.
3. 자주 쓰는 해시태그 3~5개

## 2. 브랜드 색과 글꼴

1. 배경색, 강조색, 카드색, 글자색, 형광 표시색. 브랜드 가이드 파일이 있으면 그 파일에서 가져오고, 없으면 사용자에게 고르게 한다.
2. 글꼴 이름(모션·요약 카드·썸네일용). 상업적으로 쓸 수 있는 글꼴인지 사용자에게 확인을 부탁한다.
3. 대비 검사: 강조색 바탕 위 흰 글자는 대비가 모자라는 경우가 많다(4.5:1 미만). 그럴 때는 바탕 위 글자를 어두운 색으로 제안한다.

## 3. 캡컷 템플릿 초안 두 개 (가장 중요)

스크립트는 글꼴·색·테두리·애니메이션을 직접 정하지 않고, 사용자가 만든 초안의 글자 서식을 그대로 복제한다. 그래서 사용자의 평소 스타일이 유지된다.

1. 롱폼 템플릿: 캡컷에서 16:9 새 프로젝트를 만들고, 평소 쓰는 자막 서식으로 자막 한 줄을 넣어 저장한다. 그 초안 이름 → `longform_template_draft`.
2. 숏폼 템플릿: 평소 올리는 숏폼 초안 중 하나를 고르거나 새로 만든다. 글자 트랙 순서가 중요하다.
   1. 첫 번째 글자 트랙: 훅(위쪽 큰 문구) 서식
   2. 두 번째 글자 트랙: 자막 서식
   이름 → `shorts_template_draft`. 숏폼 배치값(`shorts_layout`의 자막 높이 y, 크기)은 그 초안의 실제 값을 읽어 채운다(`capcut_draft.py`로 트랙을 열어 `clip.transform.y`, `clip.scale` 확인).
3. 이미 쓰는 숏폼 초안이 여러 개 있으면 최근 것 몇 개를 읽어 공통점(배경, 원본 위치, 훅 위치, 자막 위치, 효과음)을 표로 보여 주고 확인받는다. 이 표를 `profile.json`의 `shorts_style_note`에 적어 둔다.

## 4. 효과음과 BGM

1. 사용자가 실제로 쓰는 효과음 폴더를 묻는다. 캡컷 초안이 많으면 초안들의 오디오 소재 사용 횟수를 세어 자주 쓰는 소리 상위 10개를 보여 주고 고르게 한다.
2. 쓰임별로 하나씩 정한다: 전환(whoosh), 완료(ding), 클릭(click), 자막 타자음(선택). 경로를 `sfx`에 적는다.
3. 효과음 파일 앞에 무음이 있으면 소리가 늦게 들린다. 앞 무음을 잘라 낸 사본을 만들어 그 경로를 쓴다:
   `ffmpeg -i in.mp3 -af silenceremove=start_periods=1:start_threshold=-45dB out.mp3`
4. BGM은 저작권을 사용자가 확인한 곡만. 기본값은 맨 앞 하이라이트와 마지막 인사에만 넣고 본편에는 넣지 않는 것(말소리를 가리지 않게).
5. 효과음·BGM 파일은 스킬에 넣어 배포하지 않는다. 각자 가진 파일 경로만 적는다.

## 5. 나머지

- `work_root`: 프로젝트 폴더를 만들 곳. `export_dir`: 캡컷 내보내기 폴더.
- `encoder`: 엔비디아 그래픽카드가 있으면 `h264_nvenc`(빠름), 없으면 `libx264`.
- `blog_tone_file`: 블로그 말투 예시 글 파일(있으면). 없으면 사용자가 쓴 블로그 글 2~3편 주소를 받아 말투를 정리해 둔다.
- `thumbnail_tool`: 이미지 생성 도구(쓰는 것이 있으면), 캔바, 직접 제작 중 무엇을 쓰는지.

## 끝나면

`profile.json`을 쓰고 `python scripts/check_env.py`로 확인한 결과를 보여 준다. 빠진 프로그램은 설치 명령을 안내한다(설치는 사용자 확인 후).

# 1단계 편집: 녹화 → 컷 초안 → 하이라이트·요약 카드·효과음

## 1. 받아쓰기

```
python scripts/transcribe.py "<원본.mp4>" "<작업폴더>/받아쓰기"
```
- 1시간 녹화는 GPU로 몇 분, CPU로는 수십 분 걸린다고 미리 알린다.
- 녹화 앞뒤의 대기·잡담 시간을 알면 `--start`, `--end`로 줄인다.

## 2. 쓸 구간 고르기 → 컷 초안

1. `transcript.txt`를 처음부터 끝까지 읽고 쓸 구간을 고른다. 목표 길이는 8~12분.
2. 빼는 것: 인사·대기, 화면 공유가 안 된 구간, 같은 설명 반복, 질문 대기, 개인 이름이 소리로 나오는 문장.
3. 구간 경계는 `words.json`의 단어 시각에 맞춘다. 시작은 첫 단어 0.1~0.15초 전, 끝은 마지막 단어 0.2~0.3초 뒤.
4. 구간표를 사용자에게 보여 준다: 번호 | 원본 시각 | 길이 | 내용 한 줄. 확인받은 뒤 `project.json`의 `cuts`에 넣는다.
5. 받아쓰기 오타(도구 이름 등)는 `captions.fix`에 적는다.
6. `python scripts/make_cut_draft.py project.json --dry` → `컷초안_자막.txt`로 자막을 먼저 확인하고, 괜찮으면 `--dry` 없이 실행해 초안을 만든다.
7. 사용자가 캡컷에서 컷을 다듬는다. 다음 단계는 사용자가 다듬은 초안을 읽어서 한다.

가림이 필요한 영상이면 2단계(`references/privacy.md`)를 먼저 하고, `masked_video`에 가림본을 넣은 뒤 컷 초안을 만든다. 가림본은 원본과 시각이 같아서 `cuts`를 그대로 쓴다.

## 3. 하이라이트 (맨 앞 20~30초)

- 시청자가 "이것까지 된다고?" 할 장면 4~6개를 자막 경계에 맞춰 잘라 맨 앞에 붙인다. 결과·숫자·자동화 장면 위주, 마지막은 한 문장 정리.
- 화면 구석에 "하이라이트" 표시(강조색 또는 형광 표시색), BGM은 이 구간에만. 끝에 로고 0.5~0.6초 + 전환음 → 본편.
- 하이라이트 이음새에 앞 문장 끝 말("그리고")이 새지 않는지 검수에서 확인한다.

## 4. 주제별 요약 카드

- 주제가 바뀌는 곳마다 4~5초 카드: "요약" 표시 + 주제 이름 + 핵심 3줄.
- 3줄은 그 주제에서 실제로 한 말을 줄인 것만 쓴다.
- 넣는 위치는 받아쓰기(검수용 `받아쓰기.json`)의 문장 사이 빈틈에 맞춘다. 카드 동안 영상은 멈추고, BGM을 쓰는 구간이면 같은 곡으로 빈자리를 채운다.
- 카드는 메인 트랙 안에 끼워 넣는다(빈칸을 만들지 않는다). 챕터 시각의 기준이 된다.

## 5. 모션 그래픽 (선택)

- 넣는다면 장면마다 3~6초짜리 핵심 순간만 보이게 하고, 사이에는 실제 시연 화면이 보이게 한다. 본편 전체를 덮으면 시연이 안 보인다.
- 도구: HyperFrames 스킬(HTML → 영상)이 있으면 장면별로 투명 배경으로 렌더해 캡컷 위 트랙에 둔다. 장면별 파일로 나눠 바뀐 장면만 다시 렌더한다.
- 색·글꼴은 `profile.json`의 `brand`만 쓴다.
- 부품 예: 장면 제목(글자가 떨어짐), 앱 창 모양 카드, 실제 캡처를 종이처럼 붙이기, 캡처 일부를 오려 크게, 형광펜, 번호 카드, 손그림 화살표, 숫자 올라가기, 커서 클릭.
- 먼저 2~3장면만 렌더해 보여 주고, 확정되면 나머지를 같은 값으로 만든다.
- 감탄 도장("대박!" 같은 글자)은 과장으로 보일 수 있어 사용자가 원할 때만.
- 움직이는 배경(계속 흔들리거나 바뀌는 질감)은 롱폼에서 산만하다는 반응이 많다. 기본은 멈춘 배경.

## 6. 효과음·자막

- 효과음은 `profile.json`의 `sfx`만 쓴다. 모션이 화면에 안 보이는 구간에는 넣지 않는다. 같은 소리가 너무 잦지 않게.
- 시각 보정: 전환음은 화면 변화보다 0.1초쯤 먼저, 떨어져 찍히는 모션은 찍히는 순간에.
- 클릭음은 화면에서 실제로 클릭하는 곳, 또는 자막에 "누르/클릭/설치/다운로드" 같은 말이 나오는 곳.
- 자막은 한 덩어리 16자 안팎, 문장 끝·0.6초 넘는 쉼에서 끊는다. 사용자가 고친 자막 글자는 그대로 두고 나누는 위치만 바꾼다.

## 7. 근거 화면 (선택)

- 영상 속 주장(회사 정보, 출시일 등)을 화면에 붙일 때는 1차 출처(공식 사이트, 기사)를 직접 확인하고 출처 이름과 날짜를 작게 적는다.
- 말과 사실이 다르면 사실에 맞춘 문구를 쓰고 사용자에게 알린다.
- 기사 본문은 옮기지 않는다. 제목과 날짜만.

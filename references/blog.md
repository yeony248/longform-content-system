# 10단계 롱폼 → 블로그 초안 (요청할 때만)

발행은 하지 않는다. 초안 파일과 이미지까지.

## 근거
- 말투: `profile.json`의 `blog_tone_file`(사용자 블로그 글 예시). 없으면 사용자가 쓴 글 2~3편을 받아 말투를 먼저 정리한다.
- 내용: 롱폼 검수 받아쓰기(`검수/받아쓰기.json`)와 요약 카드 주제 순서. 영상에서 한 말과 실제 화면만 쓴다.
- 숫자·사실: 영상에서 말한 것, 화면에 나온 것, 확인한 출처만. 확인이 안 되는 것은 `[확인 필요]`를 남긴다.
- 링크: 설명란과 같은 것(도구 공식 링크, 유튜브 풀영상, 내 링크).

## 만들 것
양식: `templates/블로그_초안_양식.md`
1. 제목 후보 3개 (검색어 나열형, 도구 한글명 + 영문명 + 하는 일)
2. 본문: 요약 카드 주제를 소제목으로, 각 소제목 아래 영상에서 한 말을 블로그 말투로 풀고 그 장면 캡처 자리를 표시
3. 캡처: 롱폼 최종 mp4에서 해당 시각 프레임을 `<작업폴더>/블로그/img_XX.jpg`로 저장
   `ffmpeg -ss <초> -i <롱폼.mp4> -frames:v 1 -q:v 2 img_01.jpg`
   가림본에서 뽑았어도 한 장씩 열어 개인정보가 없는지 확인한다.
4. 유튜브 풀영상 링크: 본문 중간과 끝
5. 키워드 줄

파일: `<작업폴더>/블로그/블로그_초안.md` + 이미지.

## 사람이 직접 쓸 자리
AI가 쓴 글을 그대로 올리면 검색 노출이 제한될 수 있다는 경험담이 많다(플랫폼이 공식으로 밝힌 기준은 확인하지 못함). 사용자가 직접 보탤 자리(경험 한두 문장)를 `[직접 추가]`로 표시해 둔다.

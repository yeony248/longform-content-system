# 2단계 글자 가림 (쓴 구간만)

화면 전체를 흐리면 시청자가 무엇을 하는지 못 본다. 읽히면 안 되는 글자만 가린다.

## 가릴 것

- 사람 이름, 업체명(실제 거래처·수강생·고객), 주소, 전화번호, 이메일, 카카오 채널 주소
- 메신저·브라우저 사이드바의 대화 제목·탭 제목 줄. 메뉴 이름(새 대화, 탭 같은 고정 메뉴)은 남긴다. 사이드바 열 전체를 가리면 "무슨 메뉴가 있는지 모르겠다"는 반응이 나온다.
- 뉴스 첫 화면의 기사 제목·사진 묶음(정치 기사 등 영상 주제와 무관한 내용)
- 모션에 쓰는 캡처 이미지도 같은 기준으로 미리 가린다.

## 순서

1. `project.json`의 `privacy.words`에 아는 이름·업체명을 적는다. 사용자에게 "화면에 나오면 안 되는 이름"을 묻는다.
2. `python scripts/privacy_scan.py project.json` → `가림/boxes.json`, `가림/ocr_all.tsv`
3. `ocr_all.tsv`를 읽고 목록에 없는 이름·업체명·주소 줄을 찾아 `privacy.words`에 더한 뒤 2번을 다시 돌린다.
4. 사이드바처럼 늘 같은 자리에 있는 영역은 `privacy.regions`에 시각·좌표로 직접 적는다. 메뉴 이름 줄은 빼고 목록 줄만 잡는다.
5. `python scripts/privacy_render.py project.json` → 가림본(원본과 같은 길이, 쓰지 않는 시간은 검은 화면)
6. `python scripts/privacy_scan.py project.json --check "<가림본.mp4>"` → `가림/check.txt`가 0건이 될 때까지 3~6을 반복한다. 검사는 1초에 4장.
7. 가림본에서 가린 장면 몇 장을 프레임으로 뽑아 내용(무엇을 하는지)은 읽히는지 사용자에게 보여 준다.

## 알아 둘 것

- 블러는 큰 상자(가로·세로 150px 이상)에만 쓴다. 작은 상자는 블러 반경이 상자 크기에 묶여 글자가 다시 읽히므로 모자이크로 한다(스크립트가 자동으로 고른다).
- OCR은 단어를 붙여서 낸다. 그래서 공백을 빼고 비교하고, 줄 상자를 글자 위치 비율로 잘라 단어 상자를 만든다.
- 스크롤하는 순간에는 글자가 0.5초 사이에 상자 밖으로 나간다. 검사에서 스크롤 구간이 걸리면 그 시간만 대화 영역 전체를 `regions`로 가린다.
- 줄 끝에서 잘린 이름, 스크롤 중 한 번 스친 글자도 있다. 그래서 가림본을 다시 OCR한다.
- 업체 정보는 이름만이 아니다. 주소·전화·채널 주소 줄도 같이 본다.
- 목소리로 나온 이름은 화면을 가려도 남는다. 그런 문장은 컷에서 빼거나 사용자에게 알린다.
- Windows OCR은 Windows에서만 된다. macOS에서는 OCR 없이 Claude가 프레임을 보며 `regions`를 직접 정해야 하고 시간이 더 걸린다.

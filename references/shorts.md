# 9단계 롱폼 → 숏폼 (내 숏폼 스타일 캡컷 초안)

숏폼은 롱폼 꾸밈(카드 배경, 모션, 요약 카드)을 가져오지 않는다. 사용자가 평소 올리는 숏폼 스타일(숏폼 템플릿 초안)로 만든다.
롱폼 꾸밈을 그대로 세로로 옮긴 숏폼은 "답답하고 평소 내 숏폼과 안 맞는다"는 반응을 받기 쉽다.

## 1. 후보 고르기

- 롱폼 최종 초안의 자막(또는 검수 받아쓰기)을 처음부터 끝까지 읽고 2~3개 고른다.
- 30~55초. 앞뒤 맥락 없이 이해되는 이야기 하나(문제 → 해 본 것 → 결과·팁).
- 가장 센 한 줄(결과·숫자·의외의 말)을 맨 앞에 둔다. 롱폼 순서를 그대로 따르지 않고 조각을 다시 붙여도 된다.
  예: "연락처까지 다 찾아 주더라고요"(3초)를 맨 앞에 두고 "거래처를 찾고 싶은데…"로 이어 간다.
- 뺄 것: 같은 말 반복, 인사, 롱폼 하이라이트·요약 카드 구간, 이름·업체명이 소리로 나오는 문장.
- 표로 보여 주고 확인받은 뒤 만든다: 번호 | 조각 시각 | 길이 | 훅 문구 | 고른 이유

## 2. 훅 문구

- 두 줄, 한 줄 11자 안팎. 클립 내용을 한 줄로, 보고 싶게. 영상에 없는 결과를 약속하지 않는다.
- 줄바꿈은 `\n`.

## 3. 만들기

`project.json`의 `shorts`를 채우고:
```
python scripts/make_shorts_capcut.py project.json        # 전부
python scripts/make_shorts_capcut.py project.json 2      # 2번만
```
- 조각 시각은 내보낸 롱폼 mp4 시각(= 롱폼 최종 초안 타임라인). 자막 시작·끝에 맞춰 0.05~0.1초 여유를 둔다.
- 롱폼에 자막을 구워서 내보냈으면 `crop`으로 자막 띠를 잘라 낸 사본을 쓴다(아니면 자막이 두 번 보인다). 예: 1920×1080에서 아래 180px을 자르면 `"1920:900:0:0"`. 잘라 낸 뒤 프레임을 뽑아 자막 띠가 남지 않았는지 본다.
- 초안 이름 끝에 "(초안)"처럼 표시를 붙여 사용자 초안과 구분한다. 같은 이름이 있으면 스크립트가 멈춘다.
- 효과음: `profile.json`의 `sfx.whoosh`(시작·조각 이음새), `sfx.ding`(끝 안내). 없으면 넣지 않는다.
- 끝 안내 "풀영상은 유튜브 '채널명'에서"는 마지막 몇 초에만(`end_seconds`). 영상 내내 띄우지 않는다.

## 4. 넘기기

- 사용자가 캡컷에서 다듬고(스티커·효과음 추가 등) 내보낸다.
- 캡션 안내: 인스타그램 릴스는 본문 링크가 눌리지 않으니 "프로필 링크", 유튜브 쇼츠는 "관련 동영상"에 롱폼을 연결하라고 알린다.
- ffmpeg로 완성 mp4를 바로 구워 주지 않는다. 캡컷 초안으로 줘야 사용자가 평소처럼 손볼 수 있다.

# 7단계 유튜브 비공개 업로드 + 제목·썸네일 A/B 테스트

사용자가 "올려 줘"라고 할 때만 한다. 비공개 상태까지 만들고 게시 직전에 멈춰 보고한다. 게시는 사용자가 한다.

## 준비물
| 항목 | 위치 |
|---|---|
| 영상 | `profile.json`의 `export_dir`에서 가장 최근 mp4 (캡컷 내보내기 결과) |
| 썸네일 2개 | `<작업폴더>/썸네일/유튜브용_A_….jpg`, `유튜브용_B_….jpg` |
| 제목 후보·설명란 | `<작업폴더>/업로드_제목_설명란.txt` |

브라우저는 사용자가 유튜브에 로그인해 둔 것을 쓴다. 로그인 화면이 나오면 사용자에게 로그인을 부탁한다. 비밀번호를 입력하지 않는다.

## 순서
1. 파일 확인: 영상과 썸네일 2개. 썸네일 문구를 열어 본다(제목과 짝지을 때 필요).
2. 유튜브 스튜디오 → 만들기 → 동영상 업로드 → 파일 선택. 비공개로 시작한다.
3. 세부정보
   - 제목: 후보 1번
   - 설명: 준비한 텍스트를 한 글자도 바꾸지 않고 넣고, 넣은 뒤 원문과 비교한다
   - 시청자층: 아동용 아님(사용자 영상이 아동용이면 사용자에게 묻는다)
4. A/B 테스트 (제목 옆 "A/B 테스트" 메뉴, 채널에 이 기능이 열려 있을 때)
   - 모드: 제목과 썸네일
   - 썸네일 A + 결이 맞는 제목, 썸네일 B + 결이 맞는 제목
5. 멈추고 보고한다. "게시"를 누르지 않는다.
6. 사용자가 게시했다고 하면 스튜디오 편집 화면에서 공개 상태, A/B "실행 중", 설명란을 확인한다.

## 주의
- 게시 전에 썸네일 칸에 "요건 미충족" 같은 표시가 떠도 게시 후 정상으로 바뀌는 경우가 있다. 게시 후 다시 확인한다.
- 파일 선택 창이 작업 폴더 밖 파일을 못 넣으면 허용된 임시 폴더로 복사해 올리고, 끝나면 복사본을 지운다.
- 재생목록, 유료 프로모션 표시는 임의로 정하지 않는다. 협찬이 들어간 영상이면 유료 프로모션 표시를 켜야 한다고 알린다.
- A/B 테스트 메뉴 위치와 이름은 유튜브 업데이트로 바뀔 수 있다. 화면을 보고 찾는다.

## 보고 형식
- 영상 링크, 길이
- A/B 짝: A = 제목 + 썸네일, B = 제목 + 썸네일 (짝지은 이유 한 줄)
- 설명란 반영 여부
- 남은 결정: 재생목록, 유료 프로모션 표시, 쓰지 않은 제목 후보
